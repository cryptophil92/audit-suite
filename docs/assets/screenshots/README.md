# Plan de captures publiques

Aucune capture publique n’est validée au 28 juillet 2026.

## Captures à produire

1. accueil du tableau de bord avec données synthétiques ;
2. aperçu de plan autorisé ;
3. historique vide ;
4. historique avec runs synthétiques ;
5. rapport HTML synthétique ;
6. état d’erreur API ;
7. affichage mobile et thème sombre.

## Règles de confidentialité

Avant publication :

- utiliser exclusivement des fixtures synthétiques ;
- remplacer IP, noms d’hôte, MAC, fabricants, ports et chemins personnels ;
- vérifier les métadonnées de l’image ;
- ne pas capturer d’onglet, notification ou terminal non pertinent ;
- faire relire la capture par une seconde personne ;
- conserver la source de la fixture avec la documentation.

## Format

- PNG ou WebP ;
- largeur source au moins 1 440 px pour desktop ;
- version mobile à 390 px ;
- texte lisible sans agrandissement excessif ;
- alt text descriptif dans le README ;
- nommage `dashboard-empty-light.png`, `plan-preview-dark.png`, etc.

Les wireframes préparatoires figurent dans `docs/ux/WIREFRAMES.md`.
